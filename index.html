Добавить файл или папку с Яндекс Диска

Вставьте публичную ссылку на аудиофайл или на папку с несколькими файлами. Плеер сам получит прямые ссылки и запомнит позицию каждого файла.

или Поддерживаются также прямые ссылки на .mp3 / .m4a / .ogg
Как получить ссылку:
  1. На Яндекс Диске откройте файл или папку → Поделиться → Копировать ссылку.
  2. В настройках доступа выберите «Доступ по ссылке» (не «только для меня»).
  3. Вставьте ссылку выше и нажмите «Открыть в плеере». Для папки покажется список аудиофайлов — выберите нужный, дальше можно идти кнопками ⏮ / ⏭.
Позиция хранится только в этом браузере (localStorage)

⌨️ Горячие клавиши

  • Пробел / K — воспроизвести / пауза
  • J / L или ← / → — ∓10 сек
  • Shift+J/L — ∓30 сек
  • P / N — предыдущий / следующий файл в папке
  • ↑ / ↓ — громкость, M — без звука
  • 0–9 — переход к 0%–90% файла

📱 На телефоне (Android)

  • Меню браузера ⋮ → «Установить приложение» (или кнопка выше) — появится иконка на рабочем столе, плеер откроется без адресной строки.
  • Играет в фоне при выключенном экране; перемотка и пауза доступны с экрана блокировки и из шторки уведомлений.
  • Мини-плеер внизу экрана: название, пауза, ⏮/⏭ — когда основной плеер прокручен выше.
  • Кнопка «назад» в подпапке возвращает на уровень выше, а не закрывает плеер.
  • Позиция каждого файла сохраняется в памяти телефона — можно закрыть браузер и продолжить позже.

ℹ️ Как это работает

  • Плеер использует официальный API Яндекс Диска для публичных ссылок и не скачивает файл целиком — перемотка работает сразу.
  • Плеер отключает заголовок Referer: Яндекс отдаёт 403 на запросы с чужого сайта, поэтому без этого аудио не играло бы на GitHub Pages и других хостингах.
  • «Усиление» — предусилитель до 300% для тихих записей. Работает поверх обычной громкости, пики сглаживает лимитер; настройка запоминается. На очень громких записях при 250–300% возможны искажения.
  • Автопереход к следующему файлу срабатывает и если браузер не прислал событие окончания (обрыв соединения у конца длинного файла, «залипание» на последней секунде).
  • Позиция сохраняется каждые 3 секунды и при закрытии вкладки.
  • Если файл очень большой, первое открытие может занять несколько секунд.
  • Никаких паролей и токенов не требуется — только публичная ссылка.
Плеер работает полностью в браузере. Файлы не загружаются на серверы плеера.
